PROGRAMMING FUNDAMENTALS - ASSIGNMENT NO. 2
11 C++ IF/ELSE PROGRAMS

HOW TO RUN:
1. Open Dev-C++, Code::Blocks, or Visual Studio Code with a C++ compiler.
2. Open one .cpp file.
3. Click Compile/Build and Run.
4. Enter the requested input.
5. Run each file separately because each file has its own main() function.

GITHUB UPLOAD:
1. Sign in to GitHub and create a new repository.
2. Name it Programming-Fundamentals-Assignment-2.
3. Open the repository and choose Add file > Upload files.
4. Extract this ZIP file on your computer.
5. Select the 11 .cpp files and this README.txt from the extracted folder.
6. Drag them into GitHub's upload area.
7. Click Commit changes.

GitHub stores your code; use a C++ compiler to run it.
